# UART и SPI с FIFO

Передатчик и приемник UART с контролем четности и ошибок кадра, SPI-мастер и SPI-слейв с FIFO-буферами, top модуль для платы Tang Nano 4K

## Структура
```
rtl/
    uart_tx.v - передатчик UART
    uart_rx.v - приемник UART
    uart.v - передатчик + приемник
    fifo.v - синхронный FIFO
    spi_master.v - SPI-мастер с FIFO на передачу
    spi_slave.v - SPI-слейв с FIFO на прием
    spi.v - мастер + слейв
    top.v - демо для платы: loopback UART/SPI, режим переключается кнопкой
tb/
    tb_top.v - тест верхнего модуля
constraints/
    board_check.cst - назначение пинов
```

## Сборка для платы
 
Чип GW1NSR-LV4CQN48PC6/I5 (Tang Nano 4K), 27 МГц. 
 
На выводы `debug_signal[3:0]` (пины 42, 43, 44, 46) выведены сигналы для
логического анализатора. Режим UART/SPI переключается кнопкой (пин 15),
состояние светодиода (пин 10) показывает текущий режим.
 
| Сигнал | Режим UART | Режим SPI |
|---|---|---|
| `debug_signal[0]` | данные loopback совпали | слейв принял байт |
| `debug_signal[1]` | линия TX | SCLK |
| `debug_signal[2]` | приёмник выдал байт | MOSI |
| `debug_signal[3]` | ошибка чётности или кадра | CS |
